# حالة مشروع ملعبك — ملخص للاستكمال

آخر تحديث: 2026-09-20 · **منشور على saaha.net/malaab/ على Supabase** بمصادقة حقيقية ولوحة إدارة موحّدة.
للتفاصيل التقنية العميقة: `DESIGN-SYSTEM.md`. للخطوات الجاية: `NEXT-STEPS.md`. لملاحظات الموقع كله: `../NOTES.md`.

## المعمارية (ملفات مشتركة — أي إصلاح بمكان واحد)

| الملف | المسؤولية |
|---|---|
| `data.js` | هيكل `SITE_DATA` (فاضي — بيتعبّى من Supabase) + `MalaabakSearch` (بحث + تطبيع عربي) + `SEARCH_EMPTY_COPY` |
| `malaabak-api.js` | الوصول لـSupabase: create / list / getById / update / remove / setStatus / pending / mine / uploadImage / deleteFile / book / reviews |
| `data-bridge.js` | بيجيب القوائم من Supabase ويحوّلها لشكل `SITE_DATA` (camelCase + حقول مشتقّة). بصفحات التفاصيل بياخد الصفوف من `window.__SSR__` (الرسم على السيرفر) بلا إعادة طلب. الصور المرفوعة بترجع كـ`<img>` جاهز |
| `terms.js` | شروط النشر واستخدام المحتوى (`MalaabakTerms`) — مصدر واحد للنص + `block()` (شيك بوكس موافقة) + `init()` (مودال «اقرأ الشروط كاملة»). يُحمّل بفورمات الرفع |
| `site-core.js` | الهيدر/الفوتر (`mountHeader`/`mountFooter`) + المحافظات/المدن + حقول التاريخ |
| `list-page.js` | محرك صفحات القوائم (شبكة + ترقيم + بحث + فيض وسوم + حالة "لا نتائج") — إعدادات فقط |
| `detail-core.js` | أدوات صفحات التفاصيل (مسافة Haversine + تقييمات + خريطة + فترات حجز + مشاركة) |
| `review-widget.js` | ودجت التقييمات الحقيقي على `malaabak_reviews` |
| `style.css` | كل التنسيقات (قاعدة القفزة والتدرج، `.search-empty`, `.coach-card`, `.detail-*`, `.video-logo`, `img.db-img`) |

خارج المجلد: `netlify/functions/ssr-malaab.js` (رسم صفحات التفاصيل السبعة على السيرفر)، `/admin.html` + `js/admin.js` (الإدارة)، `js/site-stats.js` (الإحصائيات).

**مبدأ**: صفحة قائمة جديدة = ~120 سطر إعدادات. صفحة تفاصيل جديدة = تستدعي `DetailCore` (+ مدخل بـ`TYPES` بـ`ssr-malaab.js` حتى تنرسم على السيرفر).

## الصفحات (كلها شغّالة على الإنتاج)

**قوائم**: `venues` `matches` `coaches` `training` `academies` `talents` `events` — `await DataBridge.load(type)` ثم `ListPage.create`؛ بحث + فلاتر + ترقيم.
**تفاصيل**: `venue-detail` `coach-detail` `academy-detail` `talent-detail` `match-detail` `training-detail` `event-detail` — تقرا `?id=` (UUID)، مرسومة على السيرفر (title/description/JSON-LD/هيرو) والمتصفّح بيكمّل الباقي. (المباريات/التمارين/الفعاليات تستخدم `DetailCore.related` بدل المسافة لأنها بلا إحداثيات).
**فورمات (تكتب على Supabase)**: `add-venue` `add-coach` `add-academy` `add-talent` `add-match` `add-training` `add-event` عبر `MalaabakAPI.create`: المباريات/التمارين/الفعاليات تظهر فوراً؛ الملعب/الموهبة/المدرب/الأكاديمية `status:pending` لحد موافقة الإدارة. كل فورم بيتحقق من تسجيل الدخول.
**دخول/تسجيل**: `login` `register` حقيقيين (Supabase Auth) — الحساب مشترك مع ساحة. (`/login.html` الرئيسية فيها جوجل وضيف كمان.)
**إدارة**: `/admin.html` الموحّدة (`malaab/admin.html` بتحوّل إلها): بانتظار المراجعة / منشور / مرفوض لكل نوع، موافقة ونشر، رفض، إخفاء وإرجاع للمراجعة، حذف نهائي (مع ملفات التخزين)، التقييمات، الحجوزات.

## قرارات مهمة

- **الأرقام لاتينية** (0123456789) بكل النصوص المعروضة. الأرقام الهندية بس جوا `MalaabakSearch.normalize` (منطق بحث).
- **بوابة الموافقة**: `status` بالقاعدة (`pending` / `approved` / `rejected`)؛ RLS بيخلّي المعتمد بس عام، وصاحب العنصر بيشوف عناصره، والمشرف بيعدّل ويحذف.
- **المقترحات = الأقرب فعلياً** بالمسافة (إحداثيات lat/lng + Haversine)، مو عشوائية. قسم "مواهب أخرى" يعرض **المكان** لا المسافة.
- **فيديو المواهب**: الرفع عنا على Storage (أو رابط يوتيوب من اللوحة عند الموافقة). غلاف خفيف (facade) — الملف ما بينحمّل إلا عند الضغط.
- **العلامة المائية** `.video-logo`/`.media-watermark`: كلمة "ملعبك" بخلفية شفافة فوق الفيديو/الصورة — عرض واجهة فقط؛ الطبع الحقيقي داخل الملف بده ffmpeg بالسيرفر (لسا).
- **شروط النشر واستخدام المحتوى** (`terms.js`): إلزامية بـ`add-talent` و`add-venue` و`add-coach` و`add-academy`.
- **الصور المرفوعة**: `DataBridge.pickImage` بيرجّع `<img class="db-img">` للروابط وإيموجي للفراغ — كل الصفحات بتحطه بالـHTML مباشرة.

## قيود بيئة الاختبار

- **لازم سيرفر محلي** من جذر الموقع (`saaha/site`) حتى تشتغل المسارات `../js/…`؛ الفتح المباشر `file://` بيطلع فاضي.
- الرسم على السيرفر ما بيشتغل محلياً إلا بسيرفر بيحاكي rewrites نتلفاي — بدونه الصفحة بتشتغل عادي من المتصفّح.
- الإحصائيات وبكسل ميتا على localhost بيطبعوا بالكونسول بس (`?stats_debug=1` / `?pixel_debug=1` للتجاوز).
