# حالة مشروع ملعبك (Static Preview) — ملخص للاستكمال

مرجع مختصر لاستكمال العمل بعد تنظيف الشات. للتفاصيل التقنية العميقة: `DESIGN-SYSTEM.md`.

## المعمارية (ملفات مشتركة — أي إصلاح بمكان واحد)

| الملف | المسؤولية |
|---|---|
| `data.js` | كل البيانات (`SITE_DATA`) + `MalaabakSearch` (بحث + تطبيع عربي) + `SEARCH_EMPTY_COPY`. المباريات/التمارين/الفعاليات بتاخد `id` تلقائي بآخر الملف |
| `store.js` | مخزن الطلبات المُرسَلة من الفورمات (`MalaabakStore`) — حفظ بـlocalStorage + دمج بـSITE_DATA + تطبيق قرارات لوحة التحكم على `status`. لازم ينحمّل بعد data.js بكل صفحة |
| `terms.js` | شروط النشر واستخدام المحتوى (`MalaabakTerms`) — مصدر واحد للنص + `block()` (شيك بوكس موافقة) + `init()` (مودال «اقرأ الشروط كاملة»). يُحمّل بفورمات الرفع |
| `site-core.js` | الهيدر/الفوتر (`mountHeader`/`mountFooter`) + المحافظات/المدن + حقول التاريخ |
| `list-page.js` | محرك صفحات القوائم (شبكة + ترقيم + بحث + فيض وسوم + حالة "لا نتائج") — إعدادات فقط |
| `detail-core.js` | أدوات صفحات التفاصيل (مسافة Haversine + تقييمات + خريطة + فترات حجز + مشاركة) |
| `style.css` | كل التنسيقات (قاعدة القفزة والتدرج، `.search-empty`, `.coach-card`, `.detail-*`, `.video-logo`) |

**مبدأ**: صفحة قائمة جديدة = ~120 سطر إعدادات. صفحة تفاصيل جديدة = تستدعي `DetailCore`.

## الصفحات (كلها مبنية وشغّالة)

**قوائم**: `venues` `matches` `coaches` `training` `academies` `talents` `events` — بحث + فلاتر سايد بار + ترقيم.
**تفاصيل**: `venue-detail` `coach-detail` `academy-detail` `talent-detail` `match-detail` `training-detail` `event-detail` — تقرا `?id=` من الرابط. (المباريات/التمارين/الفعاليات تستخدم `DetailCore.related` بدل المسافة لأنها بلا إحداثيات).
**فورمات (تحفظ فعلياً)**: `add-venue` `add-match` `add-talent` `add-coach` `add-academy` — بتجمع الحقول وبتستدعي `MalaabakStore.add`: المباراة تظهر فوراً بصفحة المباريات؛ الملعب/الموهبة/المدرب/الأكاديمية `status:pending` بيروحوا للوحة التحكم للمراجعة ومخفيين عن القوائم لحد الموافقة. أزرار "سجّل كمدرب/أكاديميتك" بصفحات القوائم بتوصل للفورمات. `login` `register` عرض فقط.
**إدارة**: `admin.html` — موافقة/رفض الطلبات المعلّقة + كتم صوت الفيديو (يُحفظ بـlocalStorage).

## قرارات مهمة

- **الأرقام لاتينية** (0123456789) بكل النصوص المعروضة. الأرقام الهندية بس جوا `MalaabakSearch.normalize` (منطق بحث).
- **بوابة الموافقة**: كل عنصر عندو `status: "approved"|"pending"`؛ القوائم تعرض approved فقط. (تنظيمية للعرض — الفرض الحقيقي بده باكند).
- **المقترحات = الأقرب فعلياً** بالمسافة (إحداثيات lat/lng حقيقية + Haversine)، مو عشوائية. لكن قسم "مواهب أخرى" يعرض **المكان** لا المسافة (بطلب المستخدم).
- **فيديو المواهب**: الرفع عنا (مو يوتيوب). غلاف خفيف (facade) — الملف ما بينحمّل إلا عند الضغط (صفر iframe/video بالبداية).
- **العلامة المائية** `.video-logo`/`.media-watermark`: كلمة "ملعبك" بخلفية **شفافة** فوق الفيديو/الصورة. عرض واجهة فقط — الطبع الحقيقي داخل الملف بده ffmpeg بالسيرفر.
- **خيار "بدون صوت"** بصفحة رفع الموهبة (طلب من الرافع).
- **تحكّم مرن بلوحة التحكم لكل فيديو**: `نشر كما هو / حذف الصوت / حذف الفيديو` (select مستقل لكل فيديو، مخزّن بـ`decisions[type:id:video:i]`) + الموافقة/الرفض الكلّي فوقهم. التنفيذ الفعلي (ffmpeg -an أو حذف الملف) بده سيرفر عند النشر.
- **شروط النشر واستخدام المحتوى** (`terms.js`): مصدر واحد يغطي الفيديو والصور لكل الأقسام (مواهب/مدربين/أكاديميات/ملاعب) — يشمل منح ترخيص النشر + إضافة الشعار + التعديل التقني + موافقة الأشخاص الظاهرين + المسؤولية القانونية + حق القرار المرن للإدارة. **الموافقة إلزامية للإرسال** بـ`add-talent` (فيديو) و`add-venue` (صورة)، مع مودال «اقرأ الشروط كاملة».
  - الموافقة إلزامية كمان بـ`add-coach` و`add-academy` (صور المدرب/الأكاديمية) — نفس `MalaabakTerms.block()`.

## قيود بيئة الاختبار

- **لازم سيرفر محلي**: `npx serve -l 3000` بمجلد `static-preview`. الفتح المباشر `file://` بيطلع فاضي (السكربتات ما بتتحمّل).
- `serve` **بيرمي `?query`** عند redirect لـ`.html` — للاختبار استخدم الرابط بدون `.html` (مثلاً `venue-detail?id=2`).
- نسخة احتياطية قبل إعادة التنظيم: `malaabak/.backup-prerefactor/`.
