# ملف ما قبل الإطلاق — ملعبك

مرجع جاهزية الإطلاق. آخر مراجعة: 2026-08-08.
الحالة العامة: **معاينة وظيفية ثابتة (localStorage فقط) — غير جاهزة للإطلاق الحقيقي بدون باكند.**

---

## ✅ سليم ومفحوص
- **كل الروابط الداخلية بين الصفحات (٢٢ صفحة) تشير لملفات موجودة** — لا رابط داخلي مكسور.
- **لا أخطاء كونسول** على الصفحات المفحوصة (index / venues / التفاصيل / admin).
- **تدفّق الإضافة يعمل محلياً**: إضافة ملعب/مباراة/موهبة/مدرب/أكاديمية → تُحفظ بـlocalStorage، تروح للمراجعة، وتظهر بالقوائم بعد موافقة لوحة التحكم.
- **لوحة التحكم**: الموافقة/الرفض تقلب الحالة فعلياً؛ تحكّم مرن بالفيديو؛ شروط النشر إلزامية.
- **شريط أقسام ساحة + الفوتر الموحّد** يعملان.

## ⚠️ أزرار/روابط غير موصولة (تحتاج عمل قبل الإطلاق)

### تحتاج باكند (وظيفية غير مكتملة)
| المكان | العنصر | الوضع |
|---|---|---|
| `login.html` / `register.html` | أزرار الدخول/إنشاء الحساب (`href="#"`) | **عرض فقط — لا مصادقة حقيقية** |
| صفحات التفاصيل | أزرار الانضمام/الحجز (`#join` / `#booking`) | بلا وظيفة — تحتاج باكند حجز |
| `talent-detail` | «تواصل مع الموهبة» | placeholder |
| `venue-detail` | «الاتجاهات» | placeholder (خرائط) |
| الفوتر (`site-core.js`) | التواصل الاجتماعي + «تواصل/الأسئلة/الشروط» (`href="#"`) | placeholder |
| رفع الصور/الفيديو | معاينة محلية فقط | لا رفع حقيقي؛ العلامة المائية overlay بلا طبع فعلي (يحتاج ffmpeg/سيرفر) |

### روابط مؤقتة مقصودة
- شريط أقسام ساحة: روابط سياحة/إعلانات (`href="#"`) مؤقتة لحين توحيد الدومين (`/`, `/tourism`).

## 🚧 الفجوات الأساسية قبل الإطلاق الحقيقي
1. **باكند** (مثل ساحة/Supabase): تخزين مشترك للبيانات بدل localStorage المحلي.
2. **مصادقة حقيقية**: تسجيل/دخول + حماية لوحة التحكم (admin).
3. **رفع الملفات فعلياً** + طبع العلامة المائية وحذف الصوت (ffmpeg على السيرفر).
4. **ربط أزرار**: الانضمام/الحجز/التواصل/الاتجاهات.
5. **صفحات ثابتة**: تواصل/الأسئلة/الشروط/الخصوصية.
6. استضافة + دومين/مسار (تحت ساحة: `/malaab`).

## خلاصة الجاهزية
الواجهات والتدفّقات **مكتملة كمعاينة**؛ الإطلاق الحقيقي يعتمد بالكامل على **إضافة الباكند والمصادقة والرفع** — وهي نفس البنية الموجودة بساحة (قابلة لإعادة الاستخدام).
